## Capture tips

- **Browser size**: Resize to **1440 × 900** or **1920 × 1080** before
  capturing (Chrome DevTools → Toggle Device Toolbar → set custom dimensions).
- **Full-page shots**: In Chrome DevTools press <kbd>Cmd/Ctrl + Shift + P</kbd>,
  type *Capture full size screenshot*, hit Enter.
- **Region snip (Windows)**: <kbd>Win + Shift + S</kbd>.
- **File size**: Compress through [TinyPNG](https://tinypng.com/) before
  committing — keeps the repo lean and GitHub README fast.
- **Avoid** screenshotting any personal info (your real name / email).

## Why an extra README in here?

GitHub doesn't track empty folders, so the very first commit needs at least
one file inside this directory. Once the real PNGs are added, this file can
stay as a guide for future contributors.
